# Contributing to OmniSight

Thank you for your interest in contributing to OmniSight!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your feature or bugfix (`git checkout -b feature/my-feature`).
3. Commit your changes with descriptive commit messages (following Conventional Commits).
4. Push your branch and open a Pull Request/Merge Request.

## Development Setup

Please refer to the `README.md` and `USER_MANUAL.md` for instructions on setting up your local environment.

## Code Standards

- Python code must be formatted with `black` and linted with `ruff`.
- JavaScript/React code must be linted with `eslint`.
- Pre-commit hooks are configured to ensure these standards.
